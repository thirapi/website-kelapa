# Shot List Foto Asli — Nagari Katapiang

**Kenapa:** foto stock generik adalah penentu #1 kesan "template".
Daftar ini presisi — tim nagari cukup mencentang satu per satu dengan HP
(mode landscape, cahaya pagi/sore, lensa bersih).

> Aturan: tanpa foto CSR generik (jabat tangan, spanduk), tanpa filter berat.
> Tone: sinematik + natural + dokumenter (`07` §1.3).
