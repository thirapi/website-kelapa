# 05: Fase Build

Stack: Next.js App Router + TypeScript + Tailwind v4 + GSAP (scroll) +
Framer Motion (state) + Lenis. Eksekusi HANYA setelah docs 00–04 dikunci.

## Fase 0: Fondasi ✅
Scaffold + token `01` + font + provider + Section/Container + Navbar/Footer +
`lib` (analytics, inquiry) + konten English `content/`.

## Fase 1: Statis ✅
Semua route §02 + section §03 sebagai markup. Gambar `next/image`
(WebP, `sizes`, lazy kecuali LCP). Form + cart dengan state.

## Fase 2: Motion ringan ✅
Reveal sekali, counter, accordion, marquee, deck produk horizontal:
`prefers-reduced-motion` fallback + varian mobile.

## Fase 3: Signature ✅
Hero parallax, timeline Process interaktif, peta Global animasi,
navbar progress, footer reveal. Tanpa pin; split rule dijaga.

## Fase 4: Integrasi & QA visual (berikutnya)
Endpoint RFQ, Maps, prefill, WA → screenshot QA semua route × viewport
(dengan guard CSS) + checklist anti-slop. Selesai = seimbang, tanpa duplikat
se-viewport, tanpa overflow, tanpa link mati.
